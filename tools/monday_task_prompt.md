Step 0 — sanity. Step 1 — QuickBooks pull, using the ccgl-qbo connector's run_qbo_query tool with exactly these two queries:
  (a) SELECT Id, TxnDate, DocNumber, TotalAmt, Balance, DueDate, CustomerRef, ShipAddr FROM Invoice WHERE TxnDate >= '2026-01-01' ORDERBY TxnDate DESC MAXRESULTS 1000
  (b) SELECT Id, DisplayName, Balance FROM Customer WHERE Active = true MAXRESULTS 1000
The invoice result is large and will be saved by the tool to a file path — pass that path straight to the ingest script. If a result comes back inline instead, first write it verbatim to tools/qbo_raw/_raw_invoices.json or tools/qbo_raw/_raw_customers.json with the Write tool. Then run:
  python3 tools/qbo_ingest.py invoices <path-to-invoice-result>
  python3 tools/qbo_ingest.py customers <path-to-customer-result>
The ingest script refuses a pull that is much smaller than last time — if it refuses, retry the query once; if it still refuses, stop and go to the failure step (don't rebuild on partial data).

Step 2 — rebuild the feed: `python3 tools/build_qbo.py`. It prints counts (invoices, $ invoiced, open, past due, mapped/unmapped customers) and lists any UNMAPPED QuickBooks customers. Do not edit tools/qbo_map.json yourself; unmapped customers just appear on the Insights tab for Dan.

Step 3 — assessments. Run `python3 tools/weekly_facts.py` and read the whole fact sheet (orders last 7 days, revenue at risk, due this week, past due, rising, fading, top 10, unassigned, one-and-done, activity by rep, open next steps, reconciliation, placeholder rows). Then write tools/assessments.json: a JSON list of 12–18 objects, each {"account": "<exact name from accounts.json or null>", "town": "<exact town or null>", "priority": "critical|high|medium|low", "kind": "risk|coverage|due|rising|protect|winback|hygiene|pipeline|ar", "headline": "<one line, specific, with a number>", "assessment": "<2–4 sentences using only figures from the fact sheet — what the numbers say and why it matters>", "action": "<who does what this week: 'Joey: …', 'Matt: …', 'Dan: …', 'Charley: …'>"}. Cover, in this order of importance: the biggest revenue at risk (quiet accounts, largest first), accounts due for reorder this week worth a call, past-due balances that should be checked before the next delivery (owner named), rising accounts to protect or expand, fading accounts and one-and-done accounts worth a win-back, coverage gaps (large unassigned accounts, overdue next steps), and one or two hygiene notes (placeholder order rows, unmapped QuickBooks customers, blank tracker totals). Owners: Joey is the rep, Matt is the sales director, Charley runs fulfillment/delivery, Dan is finance. Be direct and concrete; no filler. Use "account"/"town" values exactly as they appear in the fact sheet (the part before " / " is the name, after it the town; use null town only when the account has none).
